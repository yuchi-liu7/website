# Yuchi Liu - Personal Portfolio Website

A professional portfolio website built with R Markdown, showcasing my research experience, projects, and skills in biostatistics and data science.

🌐 **Live Site**: <https://YOUR-USERNAME.github.io/personal-website/>

------------------------------------------------------------------------

## ✨ Features {#features}

-   **Responsive Two-Column Layout**: Sidebar with personal info, main content area
-   **Custom Styling**: Professional blue color scheme with custom CSS
-   **Three Main Pages**:
    -   **Home**: About me, skills, education, and research interests
    -   **Projects**: Detailed showcase of research projects
    -   **CV**: Embedded PDF resume with download option
-   **Mobile-Friendly**: Responsive design that works on all devices
-   **Social Links**: GitHuband email in navigation

------------------------------------------------------------------------

## 📁 Project Structure {#project-structure}

personal-website/ ├── \_site.yml \# Site configuration and navigation ├── index.Rmd \# Home page ├── projects.Rmd \# Projects page ├── style.css \# Custom CSS styling ├── header.html \# Header component ├──files │ └──cv_full.pdf \# Your CV PDF ├── images │ └──profile.jpg \# Your profile photo ├── .gitignore \# Git ignore rules └── README.md

After building, a `docs/` folder will be created with the rendered HTML files.
